# Day 01 - Understanding Frameworks

**ARICT | DotCPlus .NET Workshop Series**
**Date:** 13 October 2026

## Summary

- **Framework:** Provides structure and guides application flow.
- **Library:** Provides tools that your code calls when needed.
- **Choosing a framework:** Consider project needs, language, ease of learning, community support, and scalability.
- **Learning:** Start with Hello World, explore one feature at a time, and build small projects.
